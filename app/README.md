# Aplicación web — Telco Customer Churn

Esta carpeta contiene el código fuente de la aplicación
interactiva desarrollada con Streamlit y Databricks Apps.

## Funcionalidades

- Carga de archivos CSV.
- Procesamiento mediante arquitectura Medallion.
- Ejecución de Databricks Jobs.
- Predicción de abandono de clientes.
- Integración con modelos registrados en MLflow.
- Visualización de indicadores y niveles de riesgo.
- Exportación de resultados.

## Estructura prevista

| Archivo | Descripción |
|---|---|
| app.py | Código principal de la aplicación |
| app.yaml | Configuración de despliegue |
| requirements.txt | Dependencias de Python |

## Tecnologías

- Python
- Streamlit
- Databricks Apps
- Databricks SDK
- Apache Spark
- MLflow

# Evidencias visuales — Telco Customer Churn

Esta carpeta almacena las evidencias gráficas,
capturas de pantalla, diagramas y visualizaciones
generadas durante el desarrollo del proyecto.

## 1. Objetivo

Documentar visualmente la implementación y el
funcionamiento de la plataforma, desde la ingesta
de datos hasta la generación de predicciones.

## 8. Convenciones de almacenamiento

- Formato preferente: PNG.
- Nombres de archivos descriptivos.
- Resolución suficiente para visualizar los detalles.
- Organización mediante numeración consecutiva.
- Capturas correspondientes a ejecuciones reales.
- Eliminación de información privada o confidencial.

## 9. Estado de las evidencias

El inventario anterior representa las evidencias
previstas para la documentación del proyecto.

Las imágenes se incorporarán conforme se recopilen
y verifiquen en el entorno de Databricks.

## 10. Seguridad

Las capturas no deben mostrar tokens, contraseñas,
credenciales, correos personales ni información
confidencial del entorno de trabajo.
